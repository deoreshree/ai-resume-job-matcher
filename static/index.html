About AI Resume Matcher

A production-ready, explainable, and privacy-first career intelligence platform.

Privacy-First Architecture

Unlike cloud resume services that store candidate documents, this system processes PDF and DOCX files entirely in-memory. No resumes or contact details are written to disk or persistently logged.

Zero Storage

All file extraction, NLP tokenization, and matching occurs in RAM during the active HTTP request and is immediately discarded.

Explainable Scoring

Scores are mathematically grounded with visible weights: Skills (40%), Semantic (25%), Experience (15%), Education (10%), Keywords (10%).

Offline-First AI

All core NLP parsing, catalog extraction, TF-IDF cosine similarity, and ATS heuristics function 100% offline without external API dependencies.
